## Selected work

**[TraceLab](https://github.com/ayraagrawal-byte/tracelab)** — A FastAPI tracing backend with Redis queue ingestion, a PostgreSQL persistence worker, caching, and Prometheus metrics. The repository documents a local Docker / Locust test at 100 concurrent clients: approximately 500 requests/second steady-state API ingestion, 96 ms p95 latency, and zero HTTP failures. These are enqueue results, not production traffic or database persistence throughput.

**[Recall](https://github.com/ayraagrawal-byte/recall)** · [Controlled demo](https://recall-research-workspace-demo.vercel.app/) · [Inside Recall](https://recall-research-workspace-demo.vercel.app/inside-recall) — A full-stack research workspace with PDF ingestion, hybrid semantic/BM25 retrieval, reranking, local Ollama generation, and source-linked PDF evidence. The public demo uses curated content and recorded execution; the full RAG backend runs locally. The newer live workspace is on the repository’s `recall-2.0` branch.

**[SpotOn](https://github.com/shuknuk/hackru-fall-2026)** · [Demo](https://menhel-motion.vercel.app/) — A collaborative three-person HackRU project for browser-based squat analysis, skeleton replay, and attempt comparison. Built with Next.js, MediaPipe, local IndexedDB storage, and optional AI feedback and voice guidance. The repository is owned by my teammate; I co-developed the project.

**[RUThrift](https://github.com/ayraagrawal-byte/rumad-incubator-2026)** — A four-person Rutgers Mobile App Development Incubator marketplace project using React Native, Expo, and Supabase. My work focused on authentication, profiles, and backend integration. The public snapshot includes mock listing and chat flows.
