## Selected work

**[TraceLab](https://github.com/ayraagrawal-byte/tracelab)** — A FastAPI tracing backend with Redis queue ingestion, PostgreSQL persistence, caching, and Prometheus metrics. The repository reports ~500 req/s steady-state ingestion and 96 ms p95 latency in a local Docker / Locust test with 100 concurrent clients and no HTTP failures. These are API enqueue results, not production traffic or database persistence throughput. [Case study](https://ayra-agrawal-portfolio.vercel.app/work/tracelab)

**[Recall](https://github.com/ayraagrawal-byte/recall)** — A research workspace with PDF ingestion, hybrid retrieval, reranking, local Ollama generation, and source-linked PDF evidence. The public site is a controlled demo with curated content and recorded execution; the full RAG backend runs locally. [Demo](https://recall-research-workspace-demo.vercel.app/) · [Case study](https://ayra-agrawal-portfolio.vercel.app/work/recall)

**[SpotOn](https://github.com/shuknuk/hackru-fall-2026)** — A three-person HackRU collaboration for browser-based squat analysis, skeleton replay, and attempt comparison using MediaPipe and local-first storage. I co-developed the project; the repository belongs to my teammate. Physical-camera accuracy and device acceptance remain unverified. [Demo](https://menhel-motion.vercel.app/)

**[RUThrift](https://github.com/ayraagrawal-byte/rumad-incubator-2026)** — A four-person Rutgers Mobile App Development Incubator marketplace project. My work focused on authentication, profiles, and backend integration. The public snapshot includes mock listing and chat flows.
